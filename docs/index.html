What the model actually sees

Trained on three classes only (Djokovic, Nadal, Federer). A photo of anyone or anything else still gets forced into one of these three labels, so a confident answer does not mean the subject is actually one of them.

Built for MAS1004 Data & AI, Sogang University. The model is ResNet18, trained first on ImageNet and then on images collected by the student. It runs inside this page with ONNX Runtime Web, so it works with no server at all and no picture leaves your device. How a picture is prepared for it is in app.js.
